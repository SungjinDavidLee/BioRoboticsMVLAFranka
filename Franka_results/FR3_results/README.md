# 실물 평가 2 — 200판으로 다시 학습한 GR00T N1.7(v2)과 100판 모델(v1) 비교 (Franka FR3, 2026-11-05)

> 앞선 11-02 평가(v1, 40회)는 [저장소 첫 화면](../README.md)에 있습니다. 이 폴더는 **그 뒤에 새로 한 것**만 다룹니다. 이 판들을 포함해 실험 4개를 단계 평가 S0–S9로 다시 채점한 결과는 [`../FR3_results_4exp_S0S9/`](../FR3_results_4exp_S0S9/)에 있습니다.
>
> 1. 자동 시연 100판 추가 수집 (11-05 00:14 마침, 총 200판)
> 2. 200판으로 다시 학습 (v2)
> 3. 처음 보는 배치 10개(T01–T10)에서 v1·v2를 같은 날 같은 배치로 비교 (모델마다 20판)
>
> 지시문 "put the red tube in the red slot" · 두 모델 모두 체크포인트 20k · 시작 모델 `nvidia/GR00T-N1.7-3B`

**English summary.** We collected 100 more scripted demonstrations on the real FR3, most of them (81) after the station generated a plan of 51 layouts to place by picture; 6 of the planned layouts put the yellow tube right next to the red tube and 9 put it, as a decoy, where the red tube usually sat in the first 100 episodes. We then retrained GR00T N1.7 on all 200 episodes (v2), with the same settings as the 100-episode model (v1). Ten layouts drawn at random from the same plan were held out and never collected. On them, with both models run on the same day in the order v2 → v1 → v1 → v2 per layout:

- **v1: 1/20 success (5%, Wilson 95% CI 1–24%)**
- **v2: 6/20 success (30%, 15–52%)**
- difference +25 percentage points: Fisher two-sided p = 0.09, exact within-layout permutation p = 0.08, layout bootstrap 95% CI 0 to +55 points — a clear trend, not significant at the 5% level with 20 trials per model.

The gain is mostly in finding and grasping the red tube (grasp 6/20 → 15/20, p = 0.01; above the red slot 4/20 → 12/20, p = 0.02). The remaining bottleneck is the final insertion (12 trials got above the red slot, 6 succeeded) and insertions outside the red slot (2). The comparison is confounded: v2 has twice the data and a different layout-generation strategy, and the test layouts come from the same generator as most of v2's new data. A pre-registered follow-up (v2 on layouts seen in training) and a per-trial failure-cause analysis are still to come (section 8).

- 2판 모두 실패한 배치 15개(L02, L09, L10, L13, L15, L19, L38, L39, L40, L42, L43, L45, L47, L49, L50), 뚜껑을 못 찾아 건너뜀 L28, 1판만 성공 L20·L27. L26은 7번 모두 실패해 L18로 바꿈. 마지막 9판은 L21·L46·L48·L01 각 2판 + L18 1판.

- **데이터의 한계:** "가로 랙 + 노랑 바로 옆" 조합은 없음. 작업 범위는 기존 시연 범위 근처. 로봇 왼쪽 20 cm 넘는 곳·먼 왼쪽 구역은 새 데이터가 적음.

## 3. v2 학습

v1과 같은 설정이고 데이터와 저장 주기만 다릅니다. LeRobot `lerobot_train`, `--policy.type=groot`, 시작 모델 `nvidia/GR00T-N1.7-3B`(LIBERO 파인튜닝 모델이 아님), `new_embodiment`, 행동 묶음 16, 상대 행동(그리퍼 제외), bf16, 영상 증강 켬, GPU당 batch 32 × 2장, 20,000 스텝, seed 42. 두 체크포인트의 `train_config.json`으로 확인: `pretrained_path` 없음(시작 모델에서 바로 학습), `tune_llm`·`tune_visual` false(백본 얼림), `tune_projector`·`tune_diffusion_model`·`tune_vlln` true, 영상 증강 켬, 데이터셋 v1 `local/medbio_redslot_v1` / v2 `local/medbio_redslot_v2`.

| | v1 | v2 |
|---|---|---|
| 데이터 | 100판, 34,209프레임 | 200판, 69,409프레임 |
| 20k 스텝 = | 약 37 epoch | 18.4 epoch |
| 마지막 학습 loss | 0.007–0.008 | 0.009 |
| 학습 시간 | — | 7시간 29분 (RTX PRO 6000 × 2) |

같은 스텝 수라 v2는 데이터를 절반 횟수만 봤습니다(6절 한계).

**평가 배치 T01–T10.** 홈 자세 손목 화면에 겹쳐 보여 준 목표 그림. 빨간 테두리 뚜껑 = 빨간 튜브, 노란 테두리 뚜껑 = 노란 튜브, 빈 랙의 빨간 원 = 빨간 링 칸, 숫자 = 칸 번호. 괄호 안 표시: decoy = 미끼, adjacent = 옆 칸, sparse-data zone = 데이터가 적은 구역.

**자동 판정과 최종(사람) 판정:** 40판 중 31판이 같았고, 다른 9판은 모두 실험자가 판정 버튼으로 최종 판정을 정한 판입니다(`meta.json`의 `labeled_by`·`labeled_at`).
- 부분 → 성공 6판(T01-v2-1, T02-v2-1, T06-v2-2, T07-v1-1, T09-v2-1, T09-v2-2): 꽂혀 있었는데 자동 판정이 부분으로 나와 고친 판.
- 성공 → 부분 2판(T01-v2-2, T08-v2-2 — 메모 "빨간 칸에 못 넣었음"·"다른 칸에 넣었음"): 끝 장면 확인이 되지 않아(`checked_at` 없음) 자동 판정이 손 위치·높이만으로 성공이라고 본 판. 판정 뒤에 자동 판정이 다시 계산된 적은 없습니다.
- 부분 → 실패 1판(T03-v2-2 — 메모 "빨간 튜브를 잡지 못함"): 폭으로는 쥔 것으로 나왔지만 빨간 튜브를 쥐지 못한 판.

11-02 평가와 달리 이번에는 **자동 판정이 성공을 부풀린 판이 2판** 있었고, 둘 다 끝 장면 확인이 안 된 판입니다. 끝 장면 없이 손 위치로만 낸 자동 판정은 믿기 어려우므로 성공률은 최종(사람) 판정으로 냈습니다. T01-v2-1·T09-v2-1은 판정 몇 초 뒤에 끝 장면 확인이 끝나 자동 판정이 다시 계산됐고, 그 값도 부분입니다.

- v2는 빨간 칸 위까지 간 12판 중 6판만 성공 → **마지막 꽂기**와 **빨간 칸이 아닌 곳에 꽂는 착오**가 남은 병목입니다.
- T07-v1-1(v1의 유일한 성공)은 옆 칸으로 내려가다가 다시 올라와 빨간 칸에 꽂았습니다(사람 관찰). 자동 시연 데이터에는 다시 시도하는 동작이 없습니다.

## 6. 해석과 한계

- **처음 보는 배치에서 빨간 튜브를 찾아 잡는 능력은 크게 좋아졌습니다**(잡기 30% → 75%, 빨간 칸 위 20% → 60%). 최종 성공률도 5% → 30%로 올랐지만, 모델마다 20판이라 5% 수준에서 유의하지 않습니다.
- **비교에 섞인 요인 (떼어 볼 수 없음):**
  1. 데이터 양(100 → 200판)과 배치 계획 방식(바로 옆 노랑·미끼·돌려 잡기 금지·빨간 칸 고르게)이 함께 바뀌었습니다. 늘어난 판 수 덕인지 다양성 덕인지 구분할 수 없습니다.
  2. T 배치는 v2의 새 데이터를 만든 **같은 배치 계획에서 뽑은** 배치입니다(정확히 같은 배치는 수집 안 함). v1은 이 방식의 배치를 본 적이 없으므로 비교가 v2 쪽으로 기울어 있습니다. 결과는 "같은 방식으로 뽑은 새 배치에서 새 데이터가 도움이 되는가"로 읽어야 합니다.
  3. 같은 20k 스텝이라 v2는 18.4 epoch, v1은 약 37 epoch를 학습했습니다.
- 배치는 화면의 목표 그림을 보고 사람이 놓았으므로 판마다 몇 mm·몇 도 차이가 있습니다. 실험자 한 명이 배치와 판정을 모두 했습니다.
- 11-02 평가(37%, 40회 기준 42.5%)와 숫자를 바로 비교하면 안 됩니다. 배치를 고른 방식(즉석 배치·학습 배치 재현)과 평가 규칙이 다릅니다.

## 7. 다음에 할 일

- 꽂기 정밀도: 칸 위에서 멈춘 판의 손 위치·기울기를 학습 판과 비교(8절 원인 분석).
- 자동 판정: 끝 장면 확인이 안 된 판은 손 위치로 "성공"을 주지 말고 "확인 필요"로 표시, 끝 장면에서 칸 번호까지 확인(빨간 칸이 아닌 곳에 꽂은 v2 2판). 끝 장면 확인이 자동 판정을 다시 계산할 때 이전 값도 남기기.
- 데이터: 먼 쪽·로봇 왼쪽 구역 보정 점 추가 후 수집, "가로 랙 + 노랑 바로 옆" 조합, 다시 시도 동작(사람 시연) 일부 섞기.
